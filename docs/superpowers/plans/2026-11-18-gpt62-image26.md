# GPT-6.2 and image model discovery implementation plan

**Goal:** Match the GPT-6.2 and GPT Image 2.6 model IDs available in the local CLIProxy instance, then publish release `2026.11.18`.

**Architecture:** Extend the existing text registry, reasoning validation, and system-message adapter. Keep image IDs in a separate registry and expose them only through OpenAI discovery with image-generation metadata. Image requests continue through the existing direct Images API without model substitution.

**Constraints:** Preserve the main checkout's `.gitignore` and `.omo/` work. No invented model IDs, model retirement, credential copying, live image generation, or unsupported image editing or streaming. Use Python 3.13, existing dependencies, and focused commits. User authorized PR creation, rebase merge, and release publication without another approval round.

**Evidence:** Local CLIProxy `/v1/models` on 2026-11-18 lists `gpt-6.2-astra`, `gpt-6.2-sol`, `gpt-image-2.6`, `gpt-image-2.6-flare`, and `gpt-image-2.6-sunburst`. CLIProxy registry commit `a5e8f69e56309e1ef6d6872e667da81fdfbce2ce` lists `low`, `medium`, `high`, `xhigh`, `max` for both GPT-6.2 models. OpenAI's model pages reject `none` for both.
